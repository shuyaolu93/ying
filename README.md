# Ying 交易决策研究室（Trading Decision Desk）

Ying 是一个面向个人投资者的交易决策研究工作台，提供宏观象限、决策姿态、估值、单票、组合、风险、行为自检和周复盘等模块，并配套日本蜡烛图形态学习页面。

## 当前版本

- 研究工作台和日本蜡烛图页面均通过 GitHub Pages 在线提供。
- 首次打开需要注册或登录账号，并兑换有效卡密后使用完整内容。
- 个人中心提供账号信息、卡密到期日倒计时、修改密码和留言功能。
- 管理账号可从个人中心进入统一后台，查看账号、兑换、同步状态、留言及上线后的登录记录，并生成卡密。
- 账号会话、卡密校验、留言、研究记录和蜡烛图数据接口由配套 Cloudflare Worker 提供；研究草稿、决策快照、蜡烛图收藏与阅读进度按账号同步，断网时先保存在当前浏览器。
- 市场热点解读展示国家统计局与中国人民银行近期官方动态，也支持手动填写其他来源；用户核实事实后，可生成包含影响路径、观察指标和反向证据的研究记录。官方动态按发布时间展示，不代表市场热度排名。
- 市场热点解读位于独立的 `market.html` 页面，沿用现有登录和卡密权限，热点记录单独按账号同步；旧版交易决策草稿中的热点记录会在首次访问时迁入。
- 独立页面新增企业研究九问，逐项记录利润、经营现金流、收入持续性、自由现金流、不确定性、价格预期、估值方法、两类关键证据，以及新消息改变的假设和股价反应。可按“预测归母净利润 ÷ 预测稀释后总股本 × 目标市盈率”演算情景估值，也可手动记录其他方法；所有结果均标明输入假设，不自动生成盈利预测。
- `core/risk-engine.js` 提供仓位上限、回撤熔断、减仓放行、无效价格拒绝和压力测试。
- `backend/` 保留本地分析与风控服务，部署说明见 [`backend/README.md`](backend/README.md)。

## 本地运行

后端启动：

```bash
python3.12 backend/server.py
```

运行测试：

```bash
npm test
```

浏览器回归测试：

```bash
npm install
npm run test:browser
```

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | Ying 交易决策研究室网页入口，包含登录、卡密兑换和个人中心入口 |
| `candle.html` | 日本蜡烛图形态与案例图谱，登录并兑换有效卡密后可访问 |
| `market.html` | 独立的市场热点解读页面，登录并兑换有效卡密后可访问 |
| `admin.html`、`admin.js` | 管理账号使用的统一后台，查看运营数据并生成卡密 |
| `assets/candle-chapters.js`、`assets/candle-app.js` | 章节内容、图表绘制与阅读进度同步 |
| `app.js` | 网页版研究逻辑、决策摘要和浏览器端数据管理 |
| `assets/schematics.js` | 蜡烛图示意图渲染逻辑，图谱数据由鉴权接口加载 |
| `optional/auth-gated/cloudflare/candle-data-worker.js` | 验证登录会话和卡密到期日后返回图谱数据 |
| `optional/auth-gated/` | 登录、卡密、个人中心、留言和云端风控相关脚本及部署配置 |
| `core/risk-engine.js` | 本地确定性风控核心 |
| `market-hotspots.js` | 官方动态展示、热点解读与研究记录 |

## 功能模块

1. 宏观象限（PMI 扩张/收缩 × 流动性参考评分）
2. 决策姿态（进攻 / 防守 / 均衡）
3. 估值区间
4. 单票角色卡
5. 组合配置（自动保持 100%）
6. 风险管理
7. 行为校验
8. 周复盘
9. 日本蜡烛图形态与案例学习

独立页面：市场热点解读（官方动态与手动输入）。

研究数据、快照和蜡烛图阅读进度按账号同步，同时在当前浏览器保留副本；卡密到期后需要重新兑换有效卡密才能继续使用受保护内容。

蜡烛图图谱现存储在 Cloudflare D1 的 `candle_assets` 表，由 `ying-candle-data` Worker 验证有效会话与卡密后返回。公开的 GitHub Pages 版本不再直接加载 `assets/data*.js`。图谱的可编辑 JSON 备份应保存在私有位置，不要重新提交到此公开仓库。此前公开提交的历史仍可能被访问；此改动保护的是当前发布版本和后续更新，不能撤回已经公开过的数据，也无法阻止已获授权者保存浏览器收到的内容。
